# Card Chess

Card Chess is a game feature in the Korean Survival Show "Bloody Game X".
It is a one on one game where game pieces can only move when the assiociated card is available.

At the start of the game, we decide who goes first and who goes second, the 
player that goes seconds picks two cards for themselves, and two cards for the first player.
The cards obtained depict the movement of chess pieces (the rook card means you can 
only move along rows and columns, the bishop card shows you can only move along diagonals).

Players take turns move their game pieces. To move a game piece, you must use a card and 
move the piece using that cards moveset.

Win the game by either capturing all of the opponents pieces or by surviving in the 
opponent's throne square for one whole turn.
